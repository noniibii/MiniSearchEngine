# Mini Search Engine
Search and rank information from computer science documents using C++.
## Search Topics
The included documents:

• Algorithms

• Data Structures

• Operating Systems

• Databases

• Computer Networks

• Cybersecurity
## Search Capabilities
• Single word and multi word searches

• Case insensitive matching

• Match counting

• Result scoring and ranking

• Punctuation handling

• Multiple searches in one session
## Run
Compile the program:
g++ -std=c++17 main.cpp -o search

Start the search engine:
./search
## Technologies
• C++

• File Handling

• STL

• Inverted Index
